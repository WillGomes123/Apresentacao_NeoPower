Visao Geral do Ecossistema

Arquitetura em camadas com comunicacao bidirecional via REST, WebSocket e OCPP

⚡
Camada de Apresentacao
Frontend — Clientes

NeoPower App (React Native/Expo) — App mobile para usuarios finais: login, busca de estacoes, iniciar/parar recarga, carteira, historico.
NeoRBAC Dashboard (React/Vite) — Painel administrativo web: monitoramento de carregadores, gestao de usuarios, financeiro, vouchers, notificacoes push.

Camada de Negocio
Backend — API + OCPP Server
SERVIDOR
OCPP_API (Express 5 + Node.js) — API REST central que gerencia toda a logica de negocio: autenticacao JWT, controle de carregadores, transacoes, carteiras, pagamentos (MercadoPago), notificacoes push, e servidor OCPP 1.6J integrado para comunicacao com carregadores fisicos.
base_ocpp — CSMS alternativo standalone com seguranca avancada (TLS/mTLS, Security Profiles 0-3) e frontend proprio estilo SteVe.

Fluxo de Autenticacao

JWT + Google OAuth com refresh automatico e controle de acesso baseado em roles

📱 Mobile App (NeoPower)
1
Usuario toca "Entrar com Google" na LoginScreen
2
GoogleSignin.signIn() retorna idToken do Google
3
POST /users/google-auth com o idToken
4
Backend valida com Google, cria/busca usuario, retorna JWT access + refresh tokens
5
Tokens salvos no Expo SecureStore (criptografado)
6
Axios interceptor adiciona Authorization: Bearer em todas as requisicoes. Em 401, auto-refresh do token.
💻 Dashboard Web (NeoRBAC)
1
Admin acessa pagina de Login
2
POST /users/login com email + senha
3
Backend retorna JWT com role (ADMIN, ATEM, COMUM)
4
Token armazenado em localStorage
5
api.ts wrapper inclui token em todas as fetch requests
6
Session timeout de 30 minutos de inatividade. Redirect para login em 401.

08 / 09

Comunicacao em Tempo Real

Socket.IO conecta carregadores, backend e clientes em um fluxo bidirecional continuo

BROADCAST
charger_connected
Emitido quando um carregador faz BootNotification. Mobile e dashboard atualizam status em tempo real.
BROADCAST
charger_disconnected
Emitido quando a conexao WebSocket do carregador cai. Alerta operadores imediatamente.
BROADCAST
meter_values
Dados de medicao em tempo real: potencia (kW), tensao (V), corrente (A), SoC (%). Atualiza a cada 30-60s.
BROADCAST
status_notification
Mudanca de status do conector: Available, Preparing, Charging, Finishing, Faulted.
BROADCAST
transaction_updated
Progresso da sessao de recarga: energia consumida, custo parcial, tempo decorrido.
BROADCAST
wallet_updated
Saldo do usuario atualizado apos deposito, cobranca de recarga ou resgate de voucher.
